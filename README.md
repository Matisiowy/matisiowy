## 🎵 MikrusMusic

MikrusMusic to bot Discord łączący muzykę, ekonomię, gry i narzędzia dla społeczności. Projekt zawiera również panel zarządzania serwerem oraz publiczne API dla własnych integracji.

### Najważniejsze elementy

- 🎶 Odtwarzanie muzyki, kolejka, radio i TTS
- 🎮 Gry, quizy, komendy 4fun i system poziomów
- 💸 Ekonomia: bank, przelewy, sklep, praca i rankingi
- 🛡️ Moderacja, role, powitania oraz automatyzacje serwera
- ⚙️ Panel oparty na Discord OAuth2 — ustawienia bez edycji plików
- 🧩 Publiczne API z endpointami tekstowymi, 4fun i rendererem obrazów
