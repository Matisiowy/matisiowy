# 🚀 Projekty

<table>

<td width="50%" valign="top">

### 🖥️ MikosOS

Eksperymentalny system operacyjny **x86_64 pisany od zera**.

Bez kernela Linuxa i bez gotowej bazy systemu operacyjnego.

Aktualnie posiada m.in.:

- UEFI / Limine
- własny kernel x86_64
- Ring 3 userspace
- ELF64 loader
- scheduler
- procesy i system calls
- pamięć wirtualną per-process
- VFS / RAMFS
- PS/2 keyboard & mouse
- framebuffer GUI
- własny shell
- graficzny Terminal
